# Заметки

Учебное приложение на React и TypeScript с классовыми компонентами.
Заметки загружаются с сервера. Их можно добавлять, удалять и обновлять список без перезагрузки страницы.
Пустые заметки не добавляются.

Установите зависимости:

```bash
npm install
```

Запустите сервер:

```bash
npm run server
```

В другом терминале запустите приложение:

```bash
npm run dev
```

Откройте адрес из терминала. Сервер работает на http://localhost:7070.
Заметки хранятся в памяти сервера и пропадают после его перезапуска.
